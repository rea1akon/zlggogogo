# 庄骆贵一体化管养人力资源系统

一个简单易用的本地部署人力资源管理系统，支持员工信息的录入、查询、浏览、编辑和删除。

## 功能特点

1. **员工信息录入**
   - 姓名、性别、身份证号、联系电话
   - 籍贯、岗位、所在片区、用工性质
   - 入职时间、家庭住址、备注
   - 出生时间和年龄自动根据身份证号计算

2. **身份证号智能解析**
   - 自动从身份证号提取出生时间
   - 根据出生时间和当前系统时间自动计算年龄
   - 实时更新年龄，确保数据准确性

3. **数据校验**
   - 必填项验证
   - 身份证号格式和校验位验证
   - 手机号格式验证
   - 日期有效性验证

4. **数据查询和浏览**
   - 按姓名搜索
   - 按所在片区筛选
   - 员工列表展示
   - 查看详细信息

5. **数据管理**
   - 编辑员工信息
   - 删除员工信息
   - 数据备份（导出为JSON文件）
   - 数据恢复（从JSON文件导入）

6. **Excel导入导出**
   - 支持导出全部数据或按片区筛选导出
   - 支持导入Excel文件（.xlsx, .xls格式）
   - 数据预览和校验
   - 错误提示和进度显示

7. **本地存储**
   - 使用浏览器LocalStorage存储数据
   - 数据持久化保存，刷新页面不会丢失

## 员工信息字段

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 姓名 | 文本 | 是 | 员工姓名 |
| 性别 | 下拉 | 是 | 男或女 |
| 身份证号 | 文本 | 是 | 18位身份证号，自动解析出生时间和计算年龄 |
| 出生时间 | 文本 | 只读 | 根据身份证号自动填充 |
| 年龄 | 数字 | 只读 | 根据出生时间和当前时间自动计算 |
| 联系电话 | 文本 | 是 | 11位手机号 |
| 籍贯 | 文本 | 否 | 员工籍贯 |
| 岗位 | 文本 | 是 | 岗位名称 |
| 所在片区 | 下拉 | 是 | 片所本级、庄市、骆驼、贵驷 |
| 用工性质 | 下拉 | 是 | 事业、企业、密集型、劳务派遣、劳务外包 |
| 入职时间 | 日期 | 是 | 入职日期 |
| 家庭住址 | 文本 | 否 | 住址信息 |
| 备注 | 文本 | 否 | 备注信息 |

## Excel文件格式要求

导入的Excel文件需要包含以下列（第一行为表头）：

| 列名 | 必填 | 说明 |
|------|------|------|
| 姓名 | 是 | 员工姓名 |
| 性别 | 是 | 男或女 |
| 身份证号 | 是 | 18位身份证号 |
| 出生时间 | 否 | 如果没有会自动从身份证号提取 |
| 年龄 | 否 | 如果没有会自动计算 |
| 联系电话 | 是 | 11位手机号 |
| 籍贯 | 否 | 员工籍贯 |
| 岗位 | 是 | 岗位名称 |
| 所在片区 | 是 | 片所本级、庄市、骆驼、贵驷 |
| 用工性质 | 是 | 事业、企业、密集型、劳务派遣、劳务外包 |
| 入职时间 | 是 | 日期格式 |
| 家庭住址 | 否 | 住址信息 |
| 备注 | 否 | 备注信息 |

**提示**：您可以先使用"导出Excel"功能导出一个示例文件作为模板。

## 使用方法

### 方式一：直接打开

1. 直接双击 `index.html` 文件在浏览器中打开
2. 即可开始使用系统

### 方式二：使用本地服务器（推荐）

如果您有Node.js，可以使用以下命令：

```bash
# 使用 Python
python -m http.server 8000

# 或者使用 Node.js 的 http-server
npx http-server -p 8000
```

然后在浏览器中访问 `http://localhost:8000`

## 数据安全

- 数据存储在浏览器本地，请定期使用"备份数据"功能进行备份
- 备份文件会自动包含日期信息，方便管理
- 恢复数据前请确认，会覆盖当前所有数据
